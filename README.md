# Advanced Sudoku Game

> A production-grade, full-stack algorithmic Sudoku web application featuring an independent backtracking solver, guaranteed unique-solution puzzle generation across four difficulty tiers, an intelligent step-by-step hint explainer, user authentication, and real-time statistics/leaderboards.

## 🌟 Key Features

1. **Independent Algorithmic Engine**
   - **Backtracking Solver with MRV:** Optimized solver with Minimum Remaining Values heuristic capable of solving any valid 9x9 Sudoku board in milliseconds.
   - **Guaranteed Single-Solution Generation:** Puzzles are generated by creating a complete randomized valid grid, followed by symmetry/random clue removal with real-time `countSolutions(board, limit = 2) === 1` verification.
   - **Difficulty Tiers:** Easy (40 clues), Medium (33 clues), Hard (28 clues), and Expert (24 clues).
2. **Intelligent Hint System**
   - Does not merely dump random solution numbers; analyzes current board logic and provides human explanations (e.g., *Naked Single*, *Hidden Single in Row/Column/Box*, *Conflict Detection*, and *Direct Elimination*).
3. **Advanced Gameplay & UI**
   - **Pencil Notes / Candidates:** 3×3 mini-grid inside empty cells for note-taking with automatic peer elimination upon placing final digits.
   - **Complete Move History:** Full Undo and Redo preserving candidate marks, cell values, and mistakes.
   - **Smart Highlighting:** Row, column, 3×3 box crosshairs, and identical-number highlighting.
   - **Audio Synthesizer:** Built-in Web Audio API tone generator for clicks, correct inputs, mistakes, hints, and victory fanfare without external MP3 asset lag.
   - **Timer & Pause:** Pause overlay to prevent board inspection while paused.
4. **Authentication & Persistence**
   - Password hashing via `bcryptjs` and token-based authentication via `jsonwebtoken` (JWT).
   - Seamless guest play with in-memory persistence and automatic transition for registered users.
   - Real user statistics (win rates, best completion times per difficulty, mistakes, total points).
   - Global competitive leaderboard filtered by difficulty tier.
5. **Modern Zero-Framework Frontend**
   - Pure HTML5, CSS3 Custom Properties (Dark and Light themes), and Vanilla JavaScript.

## ⚡ Quick Start & Installation

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **MongoDB** (Optional for local development; system includes automatic resilient in-memory fallback if MongoDB is not running locally).

### 2. Clone and Install Dependencies
```bash
git clone <repository_url>
cd "sudoku game"
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory (or copy from `.env.example`):
```env
PORT=5000
NODE_ENV=development
MONGO_URI=mongodb://127.0.0.1:27017/advanced_sudoku
JWT_SECRET=super_secret_jwt_key_sudoku_2026_dev_mode_change_in_prod
```

### 4. Run the Application
Start the production server:
```bash
npm start
```
Or start in development mode with nodemon auto-restart:
```bash
npm run dev
```

Open your browser and navigate to: **`http://localhost:5000`**

## 🧮 Algorithmic Design & Mathematical Principles

### 1. Board Representation & Validation
The 9×9 board is represented as a 2D array (`number[][]`), where `0` denotes an empty cell.
The validator enforces three spatial invariants simultaneously:
1. **Row Invariant:** \(\forall c_1 \neq c_2, \text{board}[r][c_1] \neq \text{board}[r][c_2]\)
2. **Column Invariant:** \(\forall r_1 \neq r_2, \text{board}[r_1][c] \neq \text{board}[r_2][c]\)
3. **Box Invariant:** \(\forall (r_1, c_1) \neq (r_2, c_2) \in \text{Box}_{b}, \text{board}[r_1][c_1] \neq \text{board}[r_2][c_2]\)

### 2. Solving & Uniqueness Proof (`countSolutions`)
A valid Sudoku puzzle must have **strictly one solution** (\(N = 1\)). To prevent multi-solution ambiguities, the generator checks candidate removals against `countSolutions(board, limit = 2)`. If `countSolutions >= 2`, the removal is rejected and the cell value is restored.

### 3. Intelligent Hint Deductions
- **Naked Single:** \(\text{Candidates}(r, c) = \{k\} \implies \text{board}[r][c] = k\).
- **Hidden Single:** In unit \(U\), \(\exists! (r, c) \in U\) such that \(k \in \text{Candidates}(r, c)\).

## 🏆 Scoring Formula

$$\text{Score} = \text{BaseScore} + \text{SpeedBonus} - \text{MistakePenalty} - \text{HintPenalty}$$

- **Base Scores:** Easy (100 pts), Medium (250 pts), Hard (500 pts), Expert (1000 pts)
- **Speed Bonus:** Up to $+50\%$ of base score when completed under target thresholds.
- **Mistake Penalty:** Configurable per difficulty (15–100 pts).
- **Hint Penalty:** Configurable per difficulty (25–200 pts).
